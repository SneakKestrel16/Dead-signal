# Bug Report

## Summary
**Title**: Exported build does not start: shipped round code uses the test helper `TestMoveStep`, which the export excludes, so movement in the shipped game is the test stand-in (walk only)
**ID**: BUG-0017
**Severity**: S1-Critical
**Priority**: P1-Fix this sprint
**Status**: Open
**Reported**: 2026-10-15
**Reporter**: orchestrator, first export of the "Dead Signal Windows" preset

## Classification
- **Category**: Build / Gameplay
- **System**: match-flow (RoundHost, story 013), lobby (LobbyScreen), controller (MovementStep)
- **Frequency**: Always, in an exported build
- **Regression**: No. It has been this way since MF-13. The editor and tests load `tests/`, which hid it

## Environment
- **Build**: `2f74a02`, exported with `--export-release "Dead Signal Windows"`
- **Platform**: Windows 11, Godot 4.7.2

## Reproduction Steps
1. Run `godot --headless --path . --export-release "Dead Signal Windows" build/windows/DeadSignal.exe`.
2. Run `build/windows/DeadSignal.exe --headless --quit-after 5`.

**Expected Result**: the game boots.
**Actual Result**:
```
SCRIPT ERROR: Parse Error: Identifier "TestMoveStep" not declared in the current scope.
SCRIPT ERROR: Compile Error: Failed to compile depended scripts.
ERROR: Failed to load script "res://src/main.gd" with error "Compilation failed".
```

## Cause
- The preset excludes `tests/*`.
- `src/feature/match_flow/round_host.gd:89` and `src/ui/lobby/lobby_screen.gd:343` pass `TestMoveStep.apply` and `TestMoveStep.make_body` from `tests/helpers/test_move_step.gd`. RoundHost's header says the real controller step had not shipped yet, and to swap both sides when it does.
- `TestMoveStep.apply` is walk-only at 4 m/s. Inference: sprint, crouch and the gait speeds of `MovementStep.step` do not apply in the shipped lobby round. The designer's playtest did not check sprint or crouch.

## Fix direction
- Ship a `src/` movement step and body factory on `MovementStep.step` (with per-body `MoveState` and `Knobs`), and use it in RoundHost and LobbyScreen.
- Leave `TestMoveStep` for tests.
- Add a guard that fails when any `src/` file names a class defined under `tests/`.
