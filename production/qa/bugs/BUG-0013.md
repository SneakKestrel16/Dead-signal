# Bug Report

## Summary
**Title**: Shapeshifter kit block sits 16 px from the screen edge, under the 48 px safe margin
**ID**: BUG-0013
**Severity**: S4-Low
**Priority**: P3-Fix when convenient
**Status**: Verified Fixed
**Reported**: 2026-10-15
**Reporter**: BUG-0010 fix agent

## Classification
- **Category**: UI
- **System**: hud-results (shapeshifter HUD, story 006)
- **Frequency**: Always
- **Regression**: No. The 16 px margin predates BUG-0010; the 28 px text now makes the block touch the right and bottom edge

## Environment
- **Build**: `b024355`
- **Platform**: Windows 11, Godot 4.7.2

## Evidence
- `production/qa/evidence/hud-budget-accessibility/after/bug-0010-trueform.png`

**Expected Result**: `design/ux/hud.md` Layout Zones: a 48 px margin from every edge.
**Actual Result**: the kit block's margin is 16 px.

## Fix direction
- Use the HUD's shared edge margin for the shapeshifter kit and status blocks.

## Fix
ShapeshifterKit (S2-S3, bottom right) and ShapeshifterFaceList (S1, top left) dropped their local 16 px `MARGIN_PX` and use `AlwaysOnHud.MARGIN_PX` (48). S4-S6 are centred or full-rect, not edge-anchored. Test: `tests/unit/hud-results/shapeshifter_hud_test.gd` `test_kit_and_face_list_use_the_hud_edge_margin` (failed before, passes after; 2 mutations caught). After: `production/qa/evidence/hud-budget-accessibility/after/bug-0013-trueform.png` (kit ends 48 px from the right and bottom edge at 1280x720).

## Verification
- **Date**: 2026-10-15, build `aa581ab` (worktree wt-verify), independent verifier.
- `shapeshifter_kit.gd` offsets and `shapeshifter_face_list.gd` position use `AlwaysOnHud.MARGIN_PX`; `test_kit_and_face_list_use_the_hud_edge_margin` passes (237 unit cases, 0 failures). No new capture.
