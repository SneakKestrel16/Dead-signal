# Bug Report

## Summary
**Title**: Eliminated clients never see Results after the shapeshifter wins by elimination
**ID**: BUG-0007
**Severity**: S2-High
**Priority**: P2-Fix next sprint
**Status**: Open
**Reported**: 2026-10-15
**Reporter**: MF-14 agent (match-flow story 014), while capturing live Results evidence

## Classification
- **Category**: Gameplay / Network
- **System**: network (`ServerMovement`), match-flow (spectators, story 007)
- **Frequency**: Always, when the last survivor is eliminated
- **Regression**: No

## Environment
- **Build**: wt-mf14 at `02f4c78` (MF-14 merge)
- **Platform**: Windows 11, Godot 4.7.2

## Reproduction Steps
1. Host a lobby round with the host seat as a survivor.
2. Let every survivor be eliminated.

**Expected Result**: every client receives the RoundEnded batch and shows the Results screen.
**Actual Result**: the eliminated clients never show Results. The server payload is correct.

## Cause (from the MF-14 report; not re-verified by the orchestrator)
- `ServerMovement._snapshot_phase` in `src/foundation/network/server_movement.gd` skips any spectator whose watched survivor has no body: `if not _players.has(watched): continue`.
- When the last survivor is removed, no spectator gets that tick's event batch, so RoundEnded never arrives.

## Workaround
- The MF-14 evidence used `--lobby-seed=6`, which makes the host the shapeshifter. That seat is never removed.

## Fix direction
- A spectator with nothing to watch still receives the tick's event batch.
