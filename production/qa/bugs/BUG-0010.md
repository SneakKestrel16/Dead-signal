# Bug Report

## Summary
**Title**: Shapeshifter HUD text (S1 face list, S2/S3 kit, S5 status) uses the 16 px default font size, under the 20 px critical-text minimum
**ID**: BUG-0010
**Severity**: S3-Medium
**Priority**: P2-Fix soon
**Status**: Verified Fixed
**Reported**: 2026-10-15
**Reporter**: HUD-10 agent (hud-results story 010), budget and accessibility pass

## Classification
- **Category**: UI / Accessibility
- **System**: hud-results (`ShapeshifterFaceList`, `ShapeshifterKit`, `ShapeshifterStatus`, story 006)
- **Frequency**: Always
- **Regression**: No

## Environment
- **Build**: wt-hud10 at `87c3058`
- **Platform**: Windows 11, Godot 4.7.2, 1920x1080 windowed, `--write-movie --fixed-fps 30`

## Reproduction Steps
1. Read `shapeshifter_face_list.gd` (row `Label.new()`), `shapeshifter_kit.gd` (`_form`, `_abilities`), `shapeshifter_status.gd` (`_stun`): no font_size override and no theme.
2. `project.godot` sets no GUI theme or default font size.

**Expected Result**: hud.md Accessibility: critical HUD text at least 20 px at 1080p (S1-S3 are Must Show for the shapeshifter; S5 Must Keep when active).
**Actual Result**: These Labels render at the engine default theme font size, 16 px (Godot's fallback theme default; training-data fact, a font-size print from a running Label settles it).

## Evidence
Source; the existing `production/qa/evidence/shapeshifter-hud/*.png` show the small text.

## Fix direction
Apply the HUD text size (AlwaysOnHud.TEXT_FONT, 28) to these Labels, ideally through one shared HUD theme (ADR-0014: sizes go through one theme).

## Fix
Commit 6f05756 (test in 0ccd197). Test: tests/unit/hud-results/shapeshifter_hud_test.gd test_s_labels_use_the_hud_text_size. ShapeshifterHud sets one Theme (default_font_size = AlwaysOnHud.TEXT_FONT) inherited by the S1, S2, S3 and S5 Labels. After: `after/bug-0010-trueform.png`, `after/bug-0010-stunned.png` (text is 28 px; the kit block now touches the right and bottom edge: its 16 px margin predates this fix and is below hud.md 48 px, to be filed separately).
