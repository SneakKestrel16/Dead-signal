# Bug Report

## Summary
**Title**: A spectating client still shows the watched survivor's taser count
**ID**: BUG-0006
**Severity**: S4-Low
**Priority**: P3-Fix when convenient
**Status**: Open
**Reported**: 2026-10-15
**Reporter**: HUD-4 agent (hud-results story 004)

## Classification
- **Category**: UI
- **System**: hud-results (H11 `TaserCount`, story 005)
- **Frequency**: Always, while spectating a survivor who holds the taser
- **Regression**: No

## Environment
- **Build**: `e3d8a9d`
- **Platform**: Windows 11, Godot 4.7.2

## Reproduction Steps
1. Spectate a survivor who has taser cartridges.

**Expected Result**: no kit element shows. The `hud.md` HUD States table says Spectating shows the roster, clock, objectives, and the watched survivor's feed and markers.
**Actual Result**: H11 reads "Taser × 2".

## Cause
- The watched survivor's CHARGES entry reaches the spectator.
- `TaserCount` subscribes to the router directly instead of reading `HudModel`, so it never sees `spectating()`.

## Fix direction
- `TaserCount` reads `HudModel`, as ADR-0014 §6 requires, and hides while `spectating()`.
