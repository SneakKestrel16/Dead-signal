## Technical Context
- **Error message**: `controller server cost, attempt 1: p50 404 us, p95 668 us, max 1132 us over 600 ticks (budget p95 <= 500 us)`
- **Likely area**: host state (power plan, thermal throttling or background load), since the same commit measured about 350 µs earlier. This is inference: re-running on mains power with the High performance plan, or on a second machine, settles it.
- **Open question**: an absolute µs budget in an automated test depends on the machine. Story 015 calls the budget a placeholder and asks for the measured number to be reported. Whether the gate should stay absolute, become relative to a calibration loop, or move to a manual perf check is a designer or lead decision.
- **Workaround**: none. Do not widen the budget before the cause is known.
