### Process Improvements
- **Plan hardware-bound and human-bound tasks with their enablers.** A task an agent cannot run (a second PC, a designer's hands) goes into a sprint only with its harness already done or planned in the same sprint, and is listed separately from agent capacity.
- **Generate data by parsing the source, not by transcribing it.** When design data lives in a doc (sketch, table), the generator reads the doc. Hand-typed coordinates need a cross-check script, as the FM-1 review did by hand.
- **Keep review plus mutation checks before every close.** They caught a defect or a test gap in every story this sprint.
